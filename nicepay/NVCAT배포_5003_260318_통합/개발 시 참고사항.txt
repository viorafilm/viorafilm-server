1. 테스트서버 사용 방법

첨부된 테스트용 가맹점다운로드 프로그램 실행 후 
가맹점 다운로드 테스트 버튼 클릭 후 성공 시 테스트 서버로 승인 가능.

* NVCAT 프로그램의 환경설정 화면에서 가맹점 다운로드 진행 시 실제 운영서버로 설정됨.


2. 카드리더 암호화 키 다운로드

카드리더 초기 설치 시 최초키 다운로드 버튼을 클릭하여 키다운로드 진행 후 거래 가능.

최초키 다운로드는 최초설치 및 카드리더 교체 혹은 CATID가 변경되었을 경우에만 수행.

* 최초키 다운로드 횟수는 20회로 제한되어 있음.
* NVCAT 내에서 최초키 다운로드 요청시 최초키다운로드가 되어 있고 CATID가 변경되지 않았을 경우
  갱신카 다운로드를 수행하도록 강제 되어 있음.



3. NVCAT 재설치시 주의사항

- 제어판에서 기존 NVCAT 제거 후 새로운 버전 설치.
- 개발 POS에서 새로 설치된 C:\NICEVCAT\NVCAT.dll 로드하여 연동 개발 진행.


4. NVCAT 머니플러스 사용시 주의사항

- NVCAT 환경설정에서 POS유형 "02 : 머니플러스" 변경
- POS에서 C:\NICEVCAT\NICEPOSICV105.dll Set_SvrInfo 함수 호출하여 IP/PORT 변경
  * TEST : 211.33.136.19 / 8101
  * REAL : 211.33.136.2  / 8101
- 머니플러스 전문 사용 (NICE_POS_to_DAEMON Spec_(ver_1.16)_머니플러스추가.doc)
- 머니플러스에서 일반 POS로 변경시
  * NVCAT 환경설정에서 POS유형 "01 : 일반" 변경
  * C:\NICEVCAT\NICEPOSICV105.dll Set_SvrInfo 함수 호출하여 IP/PORT 변경 (TEST : 211.33.136.19 / 8101, REAL : 211.33.136.2 / 8101)


5. 테스트IP / 테스트CAITD 사용시 주의사항

- 실환경에서 테스트 결제 및 테스트 가맹점 결제를 막기 위한 조치로 
  실환경에서 팝업이 나오는 경우 NVCAT 환경설정 변경이 필요.
- 테스트IP / 테스트CATID시 팝업이 나오는 경우 확인 버튼을 클릭해야 결제가 진행.
- 팝업 확인 버튼을 늦게 클릭하는 경우 VAN 통신 타임아웃으로 인해 망상취소 진행될 수도 있음.


6. 그린카드 사용시 주의사항

- 적립승인시 거래구분(0320)/거래유형(48)/WCC(I)/거래금액/적립구분/포인트구분(01)/Filler2(원포스영업일자(8)+친환경포인트(12)+특약포인트(12)) 전문 구성
- 적립취소시 거래구분(0540)/거래유형(48)/WCC(I)/거래금액/적립구분/포인트구분(11)/승인번호/승인일자/Filler2(원포스영업일자(8)+친환경포인트(12)+특약포인트(12)) 전문 구성
- 적립망상취소시 거래구분(0540)/거래유형(48)/WCC(I)/거래금액/적립구분/포인트구분(21)/승인시전문관리번호/Filler2(원포스영업일자(8)+친환경포인트(12)+특약포인트(12)) 전문 구성


7. DCC POS 2TR 거래시 주의사항

- 환율조회 요청시 거래구분(0200)/거래유형(D1)/WCC(C)/거래금액/부가세/봉사료/할부/베이스통화코드/베이스거래금액/베이스거래금액소수점 전문구성
- 환율조회 응답시 DCC거래여부 "비DCC거래 : 2" 이거나 환율조회정보 없으면 일반신용 승인
- 환율조회 응답시 DCC거래여부 "DCC거래 : 1" 이거나 환율조회정보 있으면 POS에서 수신받은 환율조회정보를 이용하여 환율선택 UI 구성
- 원화통화승인시 거래구분(0200)/거래유형(D2)/WCC(C)/거래금액/부가세/봉사료/할부/베이스통화코드/베이스거래금액/베이스거래금액소수점/환율정보(수신받은 환율조회정보 앞54바이트) 전문구성
- 자국통화승인시 거래구분(0200)/거래유형(D3)/WCC(C)/거래금액/부가세/봉사료/할부/베이스통화코드/베이스거래금액/베이스거래금액소수점/환율정보(수신받은 환율조회정보 앞54바이트) 전문구성

8. 부정취소 미사용시 주의사항
   1) 부정취소 미사용시 함수 SetCnlDisableYN(가맹점 다운로드 구분자, 부정취소 미사용 구분자)를 호출
    - 가맹점 다운로드 구분자 : 운영 거래시 "1"로 설정
    - 부정취소 미사용 구분자 : 부정취소 미사용시 "Y"로 설정
   2) 함수 Set_SvrInfo를 호출하여 IP/PORT 설정
    - TEST : 211.33.136.19 / 8101
    - REAL : 211.33.136.2  / 8101
   3) 결제 진행


9. 결제 프로세스 상태 이벤트 처리값 사용시 주의사항
   1) C:\NICEVCAT\NVCAT.ini 파일에 아래 내용 추가
    - EventYN=Y인 경우 결제 프로세스 상태 이벤트 처리값 사용 (수신).
    - EventYN=N이거나 Key값이 없는 경우 결제 프로세스 상태 이벤트 처리값 미사용
      [STATUS] #결제 프로세스 상태
      EventYN=Y #Y인 경우 사용, 나머지 미사용 (Default)
   2-1) NVCAT.dll에서 READ_STATUS API 호출해서 메시지 수신상태/상태코드 수신
    - API 설명은 "NVCAT 모듈 사용 설명서.doc" 참고
    - 메시지 수신상태가 "1"인 경우만 상태코드 수신 됨.
   2-2) C:\NICEVCAT\NVCAT.ini 파일에서 메시지 수신상태/상태코드 수신
    - [STATUS] Section에서 MSGSTATUS (메시지 수신상태), MSG (메시지 상태코드)로 확인 가능
    - 메시지 수신상태가 "1"인 경우만 상태코드 수신 됨.


10. 로그 간편 전송 기능 사용 시 주의사항
   1) LogSendInfo.ini 파일 생성
   2) INI 파일 내용 작성 ("문서\문서\NVCAT연동\INI\LogSendInfo.ini" 파일 참고)
   [Settings]
   SMTPSERVERURL= 		#SMTP서버URL
   SMTPSERVERPORT= 	#SMTP서버PORT
   SECURITY= 		#보안 (0 : NO_SECURITY, 1: TLS, 2 : SSL[DEFAULT]) 
   ID=			#URL 계정 ID
   PASSWORD=		#URL 계정 PASSWORD
   SENDEMAIL=		#보내는 사람 이메일 주소
   RECVEMAIL=		#받는 사람1 이메일 주소
   RECVEMAIL2=		#받는 사람2 이메일 주소
   RECVEMAIL3=		#받는 사람3 이메일 주소
  RECVEMAIL4=		#받는 사람4 이메일 주소
  3) LogSendInfo.ini 파일을 C:\NICEVCAT 위치에 복사
  4) NVCAT 승인내역조회 탭에서 로그전송 버튼 클릭 시 로그전송
